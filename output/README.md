# output

All outputs are written here by the scripts in `script/`, never by hand. Register each output in `metadata/provenance.json` with the script that produced it.

Hint 1. Avoid spaces in file names and use "-" or "_" to separate words, e.g. "plot-bean-yield.png" instead of "Plot Bean Yield.png".

Hint 2. Save tables as .csv and figures as .pdf or .png, so people and AI assistants can read them without special software.
