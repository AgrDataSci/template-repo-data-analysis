# docs

An optional folder for R notebooks, reports, scientific papers or any document that describes the work done in this project.

Hint 1. In an .Rmd document, call files in the output folder with "../output/filename.extension".

Hint 2. Use the R package `rticles` to get templates for scientific papers.

Hint 3. Cite the decision records in `decisions/` when you describe methods, so readers can follow why each choice was made.

Hint 4. `.github/workflows/render-paper.yml` renders `paper.Rmd` to `paper.pdf` on GitHub whenever the paper or its bibliography changes. Adapt the file names if your document has another name.
